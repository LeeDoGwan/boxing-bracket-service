# 대회 관계자: 감독관 안내

감독관은 심판 점수를 검토하고, 필요한 패널티를 등록한 뒤 경기의 최종
승자와 결과 방식을 확정합니다. 동점이어도 감독관이 최종 결정을 합니다.

## 1. 로그인과 링 선택

1. `스태프 로그인`에서 아이디와 비밀번호를 입력합니다.
2. 로그인 후 `감독관 작업실`을 엽니다.
3. `배정된 링`에서 확인할 링을 선택합니다.
4. 경기 목록에서 경기 번호를 선택합니다.

감독관에게 배정되지 않은 링의 경기는 처리할 수 없습니다.

## 2. 심판 점수 검토

선택한 경기 화면에서 다음을 확인합니다.

- 경기 상태
- 라운드별 심판 점수
- 제출 완료 심판 수
- 아직 제출하지 않은 심판 수
- 빨강·파랑 선수의 합계 점수
- 등록된 패널티와 적용 후 유효 점수

대회 심판 수는 3명 또는 5명입니다. 시작된 라운드에 대해 필요한 심판의
제출이 모두 끝나기 전에는 결과를 확정할 수 없습니다.

## 3. 패널티 등록

1. 패널티가 발생한 라운드를 선택합니다.
2. 패널티를 받은 선수 쪽을 선택합니다.
3. 패널티 점수를 양의 정수로 입력합니다.
4. 패널티 사유를 입력합니다.
5. `Add penalty` 또는 `패널티 추가`를 선택합니다.
6. 등록된 라운드와 선수를 다시 확인합니다.

패널티를 받은 선수의 점수를 직접 깎는 방식이 아닙니다. 패널티 점수는
상대 선수의 유효 점수에 더해집니다. 결과를 확정한 뒤에는 패널티를 추가할
수 없으므로 확정 전에 확인하세요.

## 4. 경기 결과 확정

1. 모든 심판 점수가 제출되었는지 확인합니다.
2. 필요한 경우 패널티와 유효 점수를 다시 확인합니다.
3. `Winner`에서 빨강 승, 파랑 승 또는 무승부를 선택합니다.
4. `Decision`에서 결과 방식을 선택합니다.
5. `Review result`를 선택합니다.
6. 확인 창에서 경기 번호, 선수, 승자, 결과 방식을 읽습니다.
7. 내용이 맞으면 `Confirm result`를 선택합니다.

합계 점수가 같으면 무승부를 선택할 수도 있고, 규정에 따라 빨강 승 또는
파랑 승을 선택할 수도 있습니다. 화면의 점수는 추천을 위한 참고값이며,
최종 결정 권한은 감독관에게 있습니다.

결과 방식의 예시는 `판정`, `KO`, `TKO`, `기권`, `실격`, `무승부`입니다.
대회 규정에 맞는 방식을 선택하세요.

## 5. 확정 결과 수정

확정 후 잘못된 내용을 발견한 경우:

1. 확정된 결과의 수정 영역을 엽니다.
2. 새 승자와 결과 방식을 선택합니다.
3. `수정 사유`에 무엇을 왜 바꾸는지 구체적으로 입력합니다.
4. `Review correction`을 선택합니다.
5. 확인 창에서 새 결과와 사유를 확인합니다.
6. `Confirm correction`을 선택합니다.

수정 사유는 필수이며 운영 기록에 동일하게 저장됩니다. 심판 점수 자체는
수정하지 않고, 확정된 경기 결과만 수정합니다.

## 6. 처리할 수 없는 경우

- 심판 제출이 모두 끝나지 않음: 심판에게 제출 여부를 확인합니다.
- 경기가 아직 시작되지 않음: 링 매니저에게 경기 시작을 요청합니다.
- 결과가 이미 확정됨: 일반 확정 대신 수정 절차를 사용합니다.
- 권한이 없음: 서비스 매니저에게 링 배정을 확인합니다.

## 7. 로그아웃

공용 기기를 사용했다면 업무가 끝난 즉시 `로그아웃`을 선택하세요.
