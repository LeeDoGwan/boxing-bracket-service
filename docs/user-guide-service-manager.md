# 대회 관계자: 서비스 매니저 안내

서비스 매니저는 시스템 전체를 관리하는 책임자입니다. 게임 매니저의
대회 운영 기능에 더해 관계자 계정과 접근 권한을 관리합니다.

## 1. 로그인

1. `스태프 로그인`에서 서비스 매니저 계정으로 로그인합니다.
2. `운영 현황`에서 현재 상태를 확인합니다.
3. `운영 메뉴`에서 필요한 관리 화면을 선택합니다.

## 2. 관계자 계정 만들기

1. `계정 관리`를 선택합니다.
2. `새 계정` 또는 계정 생성 영역을 엽니다.
3. 로그인 아이디, 이름, 임시 비밀번호를 입력합니다.
4. 역할을 선택합니다.
   - 심판
   - 감독관
   - 링 매니저
   - 게임 매니저
   - 서비스 매니저
5. 계정 상태를 활성으로 확인합니다.
6. `계정 생성` 또는 `계정 저장`을 선택합니다.
7. 발급한 아이디와 비밀번호를 해당 담당자에게 안전하게 전달합니다.

비밀번호를 다른 사람에게 공개적으로 전달하거나 문서에 평문으로 남기지
마세요. 사용하지 않는 계정은 비활성 상태로 바꿉니다.

## 3. 계정 검색과 상태 변경

1. 이름 또는 로그인 아이디로 계정을 검색합니다.
2. 역할과 상태 필터를 사용해 목록을 좁힙니다.
3. 대상 계정을 선택합니다.
4. 이름, 역할, 상태를 확인한 뒤 저장합니다.

역할을 바꾸면 기존 화면에서 수행할 수 있는 업무가 달라질 수 있습니다.
변경 후 해당 담당자에게 로그아웃과 재로그인을 안내하세요.

## 4. 링 배정

1. `배정 관리`를 선택합니다.
2. 대회를 선택합니다.
3. 역할을 선택합니다.
4. 해당 역할의 활성 계정을 선택합니다.
5. 링을 선택합니다.
6. `배정 생성`을 선택합니다.
7. 배정 목록에서 계정, 역할, 링, 활성 상태를 확인합니다.

한 사람이 여러 링을 담당하면 링별로 배정을 추가합니다. 실제 근무하지
않는 링의 배정은 `비활성화`로 변경합니다.

## 5. 권한 문제 처리

- `권한이 없습니다`: 역할 또는 링 배정을 확인합니다.
- `배정된 링이 없습니다`: 해당 역할의 활성 배정을 확인합니다.
- 로그인 실패: 계정 상태가 활성인지 확인하고 비밀번호를 재발급합니다.
- 이전 담당자가 계속 접근함: 계정을 비활성화한 뒤 기존 세션을 종료하고
  재로그인을 요청합니다.

## 6. 감사 로그 확인

`감사 로그`에서 결과 수정, 패널티 등록, 계정 변경, 배정 변경 등 중요한
작업을 확인할 수 있습니다. 대회, 역할, 행위 유형, 처리 결과와 기간을
필터로 설정한 뒤 `필터 적용`을 선택합니다.

결과 수정 기록에는 감독관이 입력한 수정 사유가 포함되어야 합니다. 사유가
없거나 내용이 부적절하면 감독관과 사실을 확인하고 운영 규정에 따라
조치합니다.

## 7. 운영 전·후 점검

### 운영 전

- 대회와 링이 등록되어 있는가
- 선수와 대진이 맞는가
- 심판 수가 3명 또는 5명인가
- 모든 관계자의 계정과 링 배정이 활성인가
- 관람자 화면에서 공지·일정·대진이 보이는가

### 운영 후

- 확정되지 않은 경기와 지연 경기가 없는가
- 결과 수정 기록을 확인했는가
- 필요하지 않은 계정을 비활성화했는가
- 감사 로그와 백업 상태를 운영 담당자에게 전달했는가

## 8. 보안 주의사항

서비스 매니저 계정은 모든 운영 기능에 접근할 수 있습니다. 공용 기기에서
사용하지 말고, 업무 종료 후 반드시 로그아웃하세요. 비밀번호를 잊어버린
경우 데이터베이스를 직접 수정하지 말고 승인된 계정 관리 절차를 사용합니다.
