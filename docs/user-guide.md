# 사용자 안내서

복싱 대회 현황 서비스는 대회 진행 상황을 공개하고, 대회 관계자가 역할에
맞는 업무를 처리하는 웹 서비스입니다. 컴퓨터나 스마트폰 사용에 익숙하지
않아도 아래 안내 순서대로 사용할 수 있습니다.

## 어떤 안내서를 읽어야 하나요?

| 사용자 | 안내서 | 로그인 |
| --- | --- | --- |
| 일반 관람자 | [관람자 안내](user-guide-audience.md) | 필요 없음 |
| 선수·코치·팀 관계자 | [대회 참여자 안내](user-guide-participant.md) | 필요 없음 |
| 심판 | [심판 안내](user-guide-judge.md) | 필요 |
| 감독관 | [감독관 안내](user-guide-supervisor.md) | 필요 |
| 링 매니저 | [링 매니저 안내](user-guide-ring-manager.md) | 필요 |
| 게임 매니저 | [게임 매니저 안내](user-guide-game-manager.md) | 필요 |

## 공통으로 알아둘 것

- 휴대전화, 태블릿, 컴퓨터의 인터넷 브라우저에서 사용할 수 있습니다.
- 대회 운영자가 알려준 링크를 열어 사용합니다.
- `다시 시도`가 보이면 인터넷 연결을 확인한 뒤 눌러 주세요.
- 공개 화면의 결과는 감독관이 최종 확정한 내용만 표시됩니다.
- 로그인 아이디와 비밀번호는 대회 운영자가 발급합니다. 다른 사람과
  공유하지 마세요.
- 화면에 `권한이 없습니다` 또는 `배정된 링이 없습니다`가 보이면 직접
  해결하려 하지 말고 게임 매니저 또는 서비스 매니저에게 문의하세요.

## 색상과 선수 표기

- 빨강 선수: Red 또는 빨강으로 표시됩니다.
- 파랑 선수: Blue 또는 파랑으로 표시됩니다.
- 경기 번호: 대회에서 자동으로 부여한 번호입니다.
- 링: 경기가 열리는 장소 또는 경기 구역입니다.

## 문의할 때 알려줄 내용

문제가 생기면 다음 네 가지를 함께 전달하면 빠르게 도움을 받을 수 있습니다.

1. 본인의 역할과 이름
2. 대회 이름과 링 이름
3. 경기 번호
4. 화면에 표시된 문구와 문제가 발생한 시간
