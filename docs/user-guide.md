# 사용자 안내서

화면·절차 확인 기준: 2026-10-10. 실제 대회 데이터와 기기를 사용하는 현장
리허설은 별도이며, 아래 안내는 현재 구현된 화면 기준입니다.

복싱 대회 현황 서비스는 대회 진행 상황을 공개하고, 대회 관계자가 역할에
맞는 업무를 처리하는 웹 서비스입니다. 컴퓨터나 스마트폰 사용에 익숙하지
않아도 아래 안내 순서대로 사용할 수 있습니다.

## 공통으로 알아둘 것

### 화면 언어 바꾸기

1. 화면 위쪽의 `언어` 선택란을 누릅니다. 영어 화면에서는 `Language`,
   일본어 화면에서는 `言語`라고 표시됩니다.
2. `한국어`, `English`, `日本語` 중 원하는 언어를 선택합니다.
3. 기기 설정에 맞추려면 `기기 언어 따르기`를 선택합니다.

처음에는 브라우저에서 사용하는 언어를 따릅니다. 지원하지 않는 언어만 설정되어
있으면 한국어로 표시합니다. 선택한 언어는 같은 브라우저에서 다음 접속에도
유지됩니다. 다른 기기에서는 다시 선택해야 합니다.

언어를 바꾸어도 입력 중인 점수와 사유는 지워지지 않습니다. 선수 이름이나
공지 내용은 운영자가 작성한 원문 그대로 표시됩니다. 아래 역할별 안내서는
한국어 화면을 기준으로 설명합니다.

### 기본 사용

- 휴대전화, 태블릿, 컴퓨터의 인터넷 브라우저에서 사용할 수 있습니다.
- 대회 운영자가 알려준 링크를 열어 사용합니다.
- `다시 시도`가 보이면 인터넷 연결을 확인한 뒤 눌러 주세요.
- 공개 화면의 결과는 감독관이 최종 확정한 내용만 표시됩니다.
- 로그인 아이디와 비밀번호는 대회 운영자가 발급합니다. 다른 사람과
  공유하지 마세요.
- 화면에 `권한이 없습니다` 또는 `배정된 링이 없습니다`가 보이면 직접
  해결하려 하지 말고 게임 매니저 또는 서비스 매니저에게 문의하세요.
- 공개 화면 맨 아래의 `스태프 로그인`에서 로그인하면 원래 보던 화면으로
  돌아갈 수 있습니다. 상단 `운영 메뉴`를 열어 본인 역할의 화면을 선택하세요.
- 현재 게임 매니저는 배정 화면에서 필요한 계정 목록을 조회할 수 없습니다.
  링 배정 생성·변경은 서비스 매니저에게 요청하세요.

## 색상과 선수 표기

- 빨강 선수: `빨강` 또는 `홍`으로 표시됩니다.
- 파랑 선수: `파랑` 또는 `청`으로 표시됩니다.
- 경기 번호: 대회에서 자동으로 부여한 번호입니다.
- 링: 경기가 열리는 장소 또는 경기 구역입니다.

## 문의할 때 알려줄 내용

문제가 생기면 다음 네 가지를 함께 전달하면 빠르게 도움을 받을 수 있습니다.

1. 본인의 역할과 이름
2. 대회 이름과 링 이름
3. 경기 번호
4. 화면에 표시된 문구와 문제가 발생한 시간
