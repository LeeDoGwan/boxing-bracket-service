## 확인된 제한과 다음 작업

- 기존 라우터·개발/테스트 의존성 보안 경고를 별도 업그레이드로 해소해야 합니다.
  개발 서버는 localhost에서만 사용합니다. 언어별 판정 용어 감수와 실제 역할별
  운영 화면의 기기 검증도 후속 통합 리허설에 포함합니다.

- 게임 매니저의 배정 화면이 서비스 매니저 전용 계정 조회 API에 의존합니다.
  이번에는 오류 안내와 문서에 반영했으며, 권한 계약을 별도 수정해야 합니다.
  그전에는 서비스 매니저가 배정을 처리합니다.
- 계정 정보 수정 시 비밀번호 입력이 항상 필수입니다. 현재 절차는 안내서에
  반영했으며, 비밀번호 변경을 별도로 분리할지 후속 검토가 필요합니다.
- 감독관 화면의 제출 건수는 점수 기록 수입니다. 기록이 없는 심판의 미제출까지
  포함한 준비 상태는 서버가 최종 판단합니다. 화면의 준비 상태 표시는 후속 개선 대상입니다.
- 다음 단계는 시연용 MariaDB와 대회·역할별 계정 데이터 준비, 실제 역할별
  브라우저 통합 검증입니다. 이후 외부 접속 배포, 보안·백업·복구 점검과
  사용자 안내서를 이용한 리허설을 진행합니다.

세부 검증은 [테스트 문서](testing.md), 사용 절차는 [사용자 안내서](user-guide.md)를
기준으로 확인합니다.
