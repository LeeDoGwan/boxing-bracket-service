# 저작권 및 라이선스 정책

Last updated: 2026-08-23

## 권리자

이 프로젝트에서 LeeDoGwan이 직접 작성하거나 제작한 원본 작업의 저작권자는
`LeeDoGwan` 개인입니다.

적용 범위는 다음과 같습니다.

- `back/`의 직접 작성 소스 코드와 테스트 코드
- `front/`의 직접 작성 소스 코드, 화면 구성과 스타일
- `docs/`의 직접 작성 문서
- 설정 파일, 데이터베이스 마이그레이션, 테스트 데이터와 프로젝트 구성
- LeeDoGwan이 직접 제작한 로고, 아이콘, 이미지 및 기타 원본 자료

저작권 고지는 저장소 루트의 [LICENSE](../LICENSE)에 기록되어 있습니다.

## 이용 조건

별도 서면 허가가 없는 경우 다음 행위를 허용하지 않습니다.

- 소스 코드나 문서의 전체 또는 일부 복제
- 수정본 또는 2차적 저작물의 작성·배포
- 다른 서비스나 제품에 포함하여 제공
- 판매, 재허락, 상업적 이용
- 원저작자 표시를 제거하거나 다른 사람의 작업으로 표시

GitHub 저장소가 공개되어 있다는 사실은 프로젝트 전체를 자유롭게 이용할
수 있다는 뜻이 아닙니다. 공개 저장소의 열람·Fork와 소스 코드의 일반적인
재사용 허가는 구분해야 합니다.

## 제3자 자료

React, Spring Boot, MariaDB 드라이버, 테스트 도구 등 외부 라이브러리와
프레임워크는 LeeDoGwan의 저작물이 아니며 각 프로젝트의 라이선스를
따릅니다. `front/package-lock.json`과 `back/pom.xml`은 의존성의 출처를
확인하는 기준입니다.

외부 글꼴, 아이콘, 이미지, 로고, 사진, 대회명 및 협회 표식은 코드와
별도로 사용 권한을 확인해야 합니다. 배포 전에 직접 사용한 외부 자료와
라이선스 URL을 별도 배포 기록에 남깁니다.

## 대회 데이터와 개인정보

선수 이름, 소속, 경기 결과, 사진 및 영상의 이용 권리는 코드 저작권과
별개입니다. 대회 주최자 또는 정보 제공자와 데이터 사용 범위를 정하고,
필요한 개인정보·초상권 동의를 별도로 확보해야 합니다.

## 공개 라이선스로 전환하는 경우

향후 누구나 코드를 사용·수정·배포할 수 있도록 공개할 계획이 생기면,
현재의 독점 이용 조건을 유지한 채 일부 문구만 추가하지 말고 프로젝트
라이선스를 별도로 검토해야 합니다. MIT 또는 Apache-2.0 같은 오픈소스
라이선스를 선택하면 허용 범위가 크게 달라집니다.

이 문서는 프로젝트 운영 기준이며, 상업 서비스나 분쟁에 대한 법률 자문을
대신하지 않습니다.
