# 대회 참여자(선수·코치·팀 관계자) 안내

현재 서비스에서 대회 참여자는 별도 로그인 없이 공개 화면을 사용합니다.
선수 등록, 대진 변경, 점수 입력은 공개 화면에서 직접 처리하지 않습니다.
정보가 잘못되었으면 대회 운영자에게 수정 요청을 해야 합니다.

## 1. 내 경기 확인하기

1. 운영자가 알려준 대회 링크를 엽니다.
2. `대진표`를 선택합니다.
3. 검색창에 선수 이름 또는 경기 번호를 입력합니다.
4. `검색`을 선택합니다.
5. 검색 결과에서 상대 선수, 경기 번호, 링, 경기 상태를 확인합니다.

선수 이름 전체를 정확히 입력하지 않아도 일부 글자로 검색할 수 있습니다.

## 2. 경기 전 확인할 내용

다음 내용을 경기 전에 확인하세요.

- 내 경기 번호
- 상대 선수 이름
- 경기 장소인 링
- 예정 순서와 일정
- 경기 상태가 `예정`, `준비`, `진행 중`, `종료` 중 무엇인지

경기 번호는 서버가 자동으로 정하므로 참여자가 번호를 직접 바꾸지 않습니다.

## 3. 경기 진행 중 확인하기

`현황` 화면에서 링별 현재 경기와 다음 경기를 확인합니다. 경기 상태가
바뀌지 않으면 `다시 시도`를 선택하거나 잠시 후 다시 확인합니다.

## 4. 경기 후 결과 확인하기

1. `최근 확정 결과` 또는 `대진표`에서 내 경기 번호를 찾습니다.
2. 경기 상세 화면에서 승자와 결과 방식을 확인합니다.
3. 결과가 아직 없으면 감독관의 최종 확정 전일 수 있습니다.

결과 방식은 예를 들어 판정, KO, TKO, 기권, 실격, 무승부 등으로 표시될
수 있습니다. 실제 적용 결과는 대회 규정과 감독관의 확정에 따릅니다.

## 5. 정보가 잘못된 경우

선수 이름, 소속, 상대, 링, 경기 번호 또는 결과에 문제가 있으면 다음
정보를 준비하여 대회 관계자에게 알려 주세요.

- 경기 번호
- 선수 이름
- 잘못 표시된 내용
- 올바른 내용
- 확인 가능한 자료가 있는 경우 그 자료

참여자는 직접 결과를 수정할 수 없습니다. 결과 수정은 감독관이 사유를
입력하여 처리하며, 수정 내용은 운영 기록에 남습니다.
