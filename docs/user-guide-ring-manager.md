# 대회 관계자: 링 매니저 안내

링 매니저는 담당 링의 경기 순서와 라운드 진행을 관리합니다. 심판 점수를
입력하거나 최종 승자를 결정하지 않습니다.

## 1. 로그인과 링 선택

1. `스태프 로그인`에서 링 매니저 계정으로 로그인합니다.
2. 상단 `운영 메뉴`에서 `링 운영`을 엽니다.
3. 담당 링을 선택합니다.
4. 경기 목록에서 운영할 경기 번호를 선택합니다.

현재 링에 설정된 경기와 다른 경기를 임의로 시작하지 마세요. 화면의 현재
경기 표시를 기준으로 처리합니다.

## 2. 경기 시작

1. 경기장 준비 상태와 선수 입장을 확인합니다.
2. 준비된 현재 경기가 없다면 `다음 경기 준비`를 누르고 `확인`을 선택합니다.
   서버가 링의 진행 순서에 따라 다음 공식 경기를 정합니다. 왼쪽에서 선택한
   경기를 임의로 다음 경기로 지정하는 기능이 아닙니다.
3. `현재 경기` 번호를 확인하고 왼쪽 목록에서 같은 경기를 선택합니다.
4. 경기 상태가 `준비`이면 `경기 시작`을 선택합니다.
5. 확인 창에서 경기 번호와 `준비 → 진행 중`을 확인하고 `확인`을 선택합니다.

다른 경기가 아직 진행 중이면 새 경기를 시작할 수 없습니다.

## 3. 라운드 시작

1. 현재 경기에서 다음 라운드 번호를 확인합니다.
2. `다음 라운드`에 표시된 번호가 실제 라운드와 같은지 확인합니다.
3. `라운드 시작`을 선택합니다.
4. 심판에게 해당 라운드 시작을 알립니다.

라운드는 1라운드부터 순서대로 시작해야 하며, 미래 라운드를 건너뛸 수
없습니다. `경기 시작`만으로 1라운드가 시작되지는 않습니다. 경기 시작 후
`다음 라운드`가 1인지 확인하고 `라운드 시작`을 눌러야 합니다.

## 4. 채점 단계로 넘기기

모든 라운드가 끝나면 `채점 단계로 전환`을 선택하고 확인 창의 `확인`을
누릅니다. 심판 점수는 시작된 라운드부터 제출할 수 있으며, 제출을 모두
마친 뒤 감독관이 결과를 확정합니다.

채점 단계에서는 링 매니저가 경기 결과를 직접 끝내지 않습니다. 감독관이
결과를 확정하면 경기 상태가 `종료`로 바뀝니다. 링 매니저가 누르는 별도
종료 버튼은 없습니다.

## 5. 다음 경기 준비

현재 경기 결과가 감독관에 의해 확정되고 경기 상태가 종료되면:

1. 현재 경기의 결과와 경기 번호를 확인합니다.
2. 링 상태와 경기장 준비를 확인합니다.
3. `다음 경기 준비`를 선택합니다.
4. 확인 창에서 링을 확인하고 `확인`을 선택합니다.
5. 새로 지정된 `현재 경기`의 번호를 확인하고 같은 경기를 선택합니다.

현재 경기가 끝나지 않았거나 다음 공식 경기가 없으면 다음 경기 준비가
거절됩니다.

## 6. 자주 보이는 문제

| 화면 안내 | 의미 | 조치 |
| --- | --- | --- |
| 이 링에서 다른 경기가 진행 중입니다. | 현재 링 경기 종료 전 | 현재 경기를 먼저 마무리 |
| 경기를 종료하려면 감독관의 결과 확정이 필요합니다. | 감독관 확정 전 | 감독관에게 검토 요청 |
| 이 링에는 다음 공식 경기가 없습니다. | 등록된 공식 경기 없음 | 게임 매니저에게 대진 확인 |
| 라운드는 순서대로 시작해 주세요. | 라운드 건너뜀 | 다음 번호를 입력 |
| 배정 권한이 없습니다. 관리자에게 확인해 주세요. | 링 배정이 없거나 해제됨 | 관리자에게 확인 |

## 7. 로그아웃

경기 운영이 끝나면 `로그아웃`을 선택합니다. 공용 태블릿에서는 다음
근무자에게 계정을 넘기기 전에 반드시 로그아웃하세요.
