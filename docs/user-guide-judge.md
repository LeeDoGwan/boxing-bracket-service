# 대회 관계자: 심판 안내

심판은 배정된 링의 경기에서 라운드별 점수를 입력하고 제출합니다. 점수
제출이 완료되면 심판 본인이 다시 수정할 수 없으므로 제출 전에 반드시
확인하세요.

## 1. 로그인

1. 대회 링크를 엽니다.
2. `스태프 로그인`을 선택합니다.
3. 발급받은 아이디와 비밀번호를 입력합니다.
4. `로그인`을 선택합니다.
5. 로그인 후 `심판 작업실` 화면으로 이동합니다.

로그인에 실패하면 아이디와 비밀번호의 영문 대소문자와 띄어쓰기를
확인하세요. 계속 실패하면 서비스 매니저에게 문의합니다.

## 2. 링과 경기 선택

1. `배정된 링` 목록에서 현재 근무할 링을 선택합니다.
2. `배정된 경기` 목록에서 진행할 경기 번호를 선택합니다.
3. 선수 이름과 경기 번호가 종이 경기표와 같은지 확인합니다.

링이 보이지 않으면 심판 계정에 링 배정이 등록되지 않은 상태입니다. 관리자가
배정을 확인해야 하므로 임의의 다른 링을 사용하지 마세요.

## 3. 라운드 점수 입력

1. 경기가 실제로 시작되었는지 확인합니다.
2. 현재 입력 가능한 라운드의 `Red score`와 `Blue score`에 점수를 입력합니다.
3. 점수는 각 선수별로 `0점부터 10점` 사이의 정수만 입력합니다.
4. 입력한 점수를 옆의 공식 기록과 다시 비교합니다.
5. `Submit round` 또는 `라운드 제출`을 선택합니다.
6. 확인 창에서 선수와 점수를 다시 확인한 뒤 `Confirm score`를 선택합니다.

미래 라운드는 링 매니저가 시작하기 전까지 입력할 수 없습니다. 진행된
라운드를 놓친 경우에는 임의로 입력하지 말고 감독관 또는 링 매니저에게
알립니다.

## 4. 제출 후 주의사항

- 제출한 점수는 심판이 수정할 수 없습니다.
- 같은 내용으로 다시 요청해도 기존 제출 내용이 유지됩니다.
- 다른 점수로 다시 제출하려 하면 거절됩니다.
- 경기 종료 또는 결과 확정 후에는 입력할 수 없습니다.
- 감독관은 모든 심판의 제출이 끝나야 결과를 확정할 수 있습니다.

잘못 입력했다면 즉시 감독관에게 알리세요. 점수를 다시 입력해 해결하려
하지 마세요.

## 5. 자주 보이는 문제

| 화면 안내 | 의미 | 조치 |
| --- | --- | --- |
| 배정된 링이 없습니다 | 근무 링 배정이 없음 | 관리자에게 배정 요청 |
| 경기가 시작되지 않았습니다 | 링 매니저가 경기를 시작하지 않음 | 링 매니저에게 확인 |
| 해당 라운드가 아직 시작되지 않았습니다 | 미래 라운드 선택 | 현재 라운드가 시작될 때까지 대기 |
| 이미 제출된 점수입니다 | 해당 라운드 제출 완료 | 감독관에게 수정 필요 여부 문의 |
| 세션이 만료되었습니다 | 로그인 시간이 끝남 | 다시 로그인 |

## 6. 로그아웃

업무가 끝나면 운영 메뉴 또는 화면의 `로그아웃`을 선택합니다. 공용 태블릿을
사용했다면 반드시 로그아웃한 뒤 기기를 다음 사람에게 전달하세요.
