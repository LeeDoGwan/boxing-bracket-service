# 대회 관계자: 게임 매니저 안내

게임 매니저는 대회 전체 운영을 준비하고 진행 상황을 확인합니다. 대회,
링, 선수, 공지, 일정과 대진을 관리할 수 있습니다. 현재 배정 화면은 계정
조회 권한 제한이 있어 관계자 링 배정은 서비스 매니저에게 요청해야 합니다.

## 1. 로그인

1. `스태프 로그인`에서 게임 매니저 계정으로 로그인합니다.
2. 화면 상단의 `운영 메뉴`에서 `운영 현황`을 열어 현재 대회 상태를 확인합니다.
3. 다른 작업도 `운영 메뉴`에서 필요한 관리 화면을 선택합니다.

## 2. 대회 준비 순서

다음 순서로 준비하면 누락을 줄일 수 있습니다.

1. `대회 관리`: 대회 이름과 기본 정보를 등록하고 `심판 수`를 3명 또는
   5명으로 설정합니다.
2. `링 관리`: 실제 경기장에 있는 링을 등록하고 상태를 확인합니다.
3. `선수 관리`: 해당 대회에 참가하는 선수 정보를 등록합니다.
4. `대진 관리`: 선수, 링, 라운드 수와 경기 유형을 등록합니다.
5. `일정 관리`: 경기, 휴식, 식사, 공연 등의 일정을 등록합니다.
6. `공지 관리`: 참가자와 관람자에게 보여줄 공지를 등록합니다.
7. 서비스 매니저에게 대회·링별 심판, 감독관, 링 매니저 배정을 요청합니다.
8. `운영 현황`: 등록 내용과 진행 상태를 최종 확인합니다.

## 3. 대진 입력

경기 번호는 직접 입력하지 않습니다. 새 경기를 저장하거나 CSV/Excel 파일을
가져오면 서버가 대회 안에서 사용할 다음 번호를 자동으로 부여합니다.

선수와 링을 잘못 선택하면 경기 진행 중 문제가 생길 수 있으므로 저장 전
선수 이름, 링, 라운드 수를 확인합니다. 이미 점수 입력이나 운영이 시작된
경기는 삭제·일정 변경이 제한될 수 있습니다.

## 4. CSV 또는 Excel로 대진 가져오기

1. `대진 관리`에서 `CSV 양식 다운로드`를 선택합니다.
2. 안내된 열 이름과 형식을 유지한 채 내용을 입력합니다.
3. 선수와 링이 먼저 등록되어 있는지 확인합니다.
4. `대진 파일`에서 파일을 선택한 뒤 `파일 가져오기`를 누릅니다.
5. 성공하면 `N건의 경기를 가져왔습니다.`를 확인합니다. 파일 내용 검증에서
   거절되면 해당 가져오기 전체가 저장되지 않습니다. 오류 문구를 운영 담당자에게
   전달하고 원본 파일을 수정합니다. 성공·실패 행을 나눈 표는 제공되지 않습니다.
6. 대진 목록에서 경기 번호와 선수·링을 다시 확인합니다.

오류 후 같은 파일이 선택된 상태에서 다시 누르면 중복 방지 번호가 유지됩니다.
파일을 다시 선택하거나 화면을 새로 열면 새로운 가져오기 요청으로 취급되므로,
같은 파일을 무조건 다시 올리지 말고 대진 목록에서 이전 등록 여부를 확인하세요.

인터넷이 끊겨 결과를 받지 못한 경우에는 이미 저장되었을 수도 있습니다.
이때도 대진 목록을 먼저 확인하고, 모르면 운영 담당자에게 문의하세요.

## 5. 관계자 링 배정

1. 대회 이름, 링 이름, 담당자 이름과 역할을 서비스 매니저에게 전달합니다.
2. 서비스 매니저가 `배정 관리`에서 등록한 뒤 활성 상태를 확인하도록 요청합니다.
3. 담당자가 로그인하여 해당 링이 보이는지 확인합니다.
4. 근무 변경 시 기존 배정 해제와 새 배정을 요청합니다.

게임 매니저에게도 `배정 관리` 메뉴는 보이지만 현재 계정 목록을 불러올 수
없습니다. 권한 오류가 나면 다른 사람의 계정을 빌리지 말고 위 절차를 사용하세요.

심판·감독관·링 매니저는 배정된 링에서만 업무를 처리할 수 있습니다.

## 6. 운영 현황과 감사 로그

- `운영 현황`: 링별 경기 상태, 심판 제출 대기, 결과 확정 대기, 15분 이상
  지연된 경기를 확인합니다.
- `감사 로그`: 누가 언제 어떤 대회 운영 변경을 했는지 확인합니다.
- 화면이 자동으로 갱신되지 않으면 `새로고침`을 선택합니다.

## 7. 수정할 때 주의할 점

경기 시작 후에는 대진을 임의로 바꾸지 않습니다. 잘못된 정보가 있으면
감독관과 서비스 매니저에게 먼저 알리고, 공식 경기표와 대조한 뒤 수정합니다.

확정된 경기 결과의 수정은 감독관의 수정 절차를 사용하며, 게임 매니저가
심판 점수를 대신 수정하지 않습니다.

## 8. 종료 전 점검

- 모든 링이 등록되어 있는가
- 선수와 대진이 맞는가
- 심판 수가 3명 또는 5명으로 설정되어 있는가
- 각 링에 심판·감독관·링 매니저가 배정되어 있는가
- 일정과 공지가 공개되어 있는가
- 운영 현황에 오류나 지연 경기가 없는가
