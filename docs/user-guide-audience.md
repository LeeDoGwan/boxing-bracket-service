# 일반 사용자(관람자) 안내

관람자는 로그인하지 않습니다. 대회 운영자가 공유한 링크를 열면 현재 경기,
일정, 대진표와 확정 결과를 확인할 수 있습니다.

## 1. 현재 경기 보기

1. 대회 링크를 브라우저에서 엽니다.
2. 첫 화면의 `현황` 화면에서 링별 경기 상태를 확인합니다.
3. `현재 경기`에서 지금 진행 중인 경기와 선수 이름을 확인합니다.
4. `대기 경기` 또는 다음 경기 목록에서 이후 순서를 확인합니다.
5. 화면이 오래된 것 같으면 `다시 시도` 또는 브라우저 새로고침을
   선택합니다.

경기 결과가 자동으로 바뀌지 않더라도 마지막으로 확인된 내용이 표시될 수
있습니다. 중요한 결과는 잠시 후 다시 확인하세요.

## 2. 대진표에서 경기 찾기

1. 상단의 `대진표`를 선택합니다.
2. 검색창에 선수 이름, 소속, 경기 유형 또는 경기 번호를 입력합니다.
3. `검색`을 선택합니다.
4. 경기 번호, 홍·청 선수, 상태와 확정된 승패를 확인합니다.
5. 경기를 누르면 해당 행이 선택됩니다. 대진표는 목록 화면이며 여기서
   경기 상세 창이 열리지는 않습니다.

검색 결과가 없으면 이름의 일부만 입력하거나 검색어를 지우고 다시
검색하세요.

라운드별 점수와 결과 방식은 `현황`의 현재 경기 또는 `최근 확정 결과`에서
경기를 눌러 확인합니다. 상세 창의 `경기 상세 닫기` 버튼으로 돌아갑니다.
최근 결과 목록에 없는 지난 경기의 상세 정보는 대회 관계자에게 문의하세요.

## 3. 오늘의 일정과 공지 확인

첫 화면에서 공지와 오늘의 일정을 확인합니다. 일정에는 경기 외에도 휴식,
식사, 공연 또는 기타 행사가 표시될 수 있습니다.

## 4. 결과가 보이지 않을 때

- 아직 감독관이 결과를 확정하지 않았을 수 있습니다.
- 경기가 시작되기 전에는 결과가 없습니다.
- `경기 정보를 불러오지 못했습니다`가 보이면 인터넷 연결을 확인하고
  `다시 시도`를 선택합니다.
- 계속 문제가 생기면 경기 번호와 함께 대회 관계자에게 문의합니다.

## 관람자가 할 수 없는 일

관람자는 점수 입력, 패널티 등록, 결과 확정, 선수 정보 수정과 대회 운영을
할 수 없습니다. 이러한 작업은 권한이 있는 대회 관계자가 처리합니다.
